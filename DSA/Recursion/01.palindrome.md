Recursion: Check Palindrome — Both Methods (Quick Revision)
There are two common ways to solve palindrome using recursion:
1. Parameterized recursion – Pass the index as a parameter.
2. Functional recursion – Use the return value of recursive calls to build the answer.

1. Parameterized Recursion
Intuition: Pass the current index i as a parameter. Compare characters from both ends and move towards the middle.
Java code
class Solution {

    boolean checkPalindrome(String s, int i) {

        // Base case
        if (i >= s.length() / 2) {
            return true;
        }

        // If characters don't match
        if (s.charAt(i) != s.charAt(s.length() - 1 - i)) {
            return false;
        }

        // Recursive call
        return checkPalindrome(s, i + 1);
    }

    public boolean isPalindrome(String s) {
        return checkPalindrome(s, 0);
    }
}


How it works
For "madam":
Call	i	Comparison	Action
1	0	m == m	Continue
2	1	a == a	Continue
3	2	Middle reached	Return true

Remember:
- Parameter i tracks progress.
- i + 1 moves towards the middle.
- Mismatch → false.
- Middle reached → true.

2. Functional Recursion
Intuition: Instead of using one index, pass two pointers: left and right.

Compare both characters and recursively move both pointers inward.
Java code
class Solution {

    boolean checkPalindrome(String s, int left, int right) {

        // Base case
        if (left >= right) {
            return true;
        }

        // If characters don't match
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }

        // Recursive call
        return checkPalindrome(s, left + 1, right - 1);
    }

    public boolean isPalindrome(String s) {
        return checkPalindrome(s, 0, s.length() - 1);
    }
}


How it works
For "madam":
Call	Left	Right	Comparison
1	0	4	m == m
2	1	3	a == a
3	2	2	Base case

Remember:
- left moves forward.
- right moves backward.
- left + 1, right - 1 reduces the problem.
- When left >= right, return true.

3. Difference between both methods
Parameterized approach	Two-pointer functional approach
Uses one index i	Uses two pointers
Right index calculated using formula	Right index passed directly
i + 1	left + 1, right - 1
Stops at i >= n/2	Stops at left >= right
Returns boolean	Returns boolean

Important clarification: Both implementations use return-based recursion. The distinction here is how we represent the recursive state, not the strict textbook distinction between parameterized and functional recursion.
4. Complexity comparison
Complexity	Both methods
Time	\(O(n)\)
Auxiliary space	\(O(n)\)

The recursion stack takes approximately \(n/2\) calls.
